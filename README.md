HAIBAZO - React Game

🚀 Giới thiệu

Dự án này là một trò chơi được xây dựng bằng React. Đây là một đề kiểm tra được cung cấp bởi công ty HAIBAZO để đánh giá kỹ năng lập trình React của ứng viên.

📦 Yêu cầu cài đặt

Node.js >= v20.17.0

npm >= 10.8.2

📂 Hướng dẫn cài đặt

1. Clone repository về máy của bạn:

 git clone https://github.com/trananhkiet0504/HAIBAZO.git

2. Cài đặt các dependencies cần thiết:

 npm install

3. Khởi chạy ứng dụng ở chế độ phát triển:

 npm run dev

Ứng dụng sẽ được chạy trên địa chỉ: http://localhost:5173/ (mặc định). Hãy mở trình duyệt và truy cập địa chỉ này để bắt đầu chơi game.

✅ Các tính năng chính

Giao diện người dùng trực quan, dễ sử dụng.

Cơ chế chơi game đơn giản, mượt mà.

Các hiệu ứng chuyển động và tương tác được xử lý tốt.

🙏 Lời cảm ơn

Tôi xin chân thành cảm ơn công ty HAIBAZO đã cung cấp đề kiểm tra này, giúp tôi có cơ hội học hỏi và nâng cao kỹ năng lập trình React. Rất mong nhận được phản hồi và góp ý từ công ty để hoàn thiện sản phẩm tốt hơn.
